# Fragmentia 

Fragmentia est un projet pédagogique réalisé en groupe de 4 personnes dans le cadre de notre cours de **Game Engine**.  

Le joueur incarne un personnage qui doit **retrouver les fragments de sa mémoire** dans un monde parallèle afin de pouvoir revenir dans son monde originel.  
Pour progresser, il doit **interroger les habitants du village**, collecter des indices et **mener l’enquête**.

## Mes contributions principales 

- **Gameplay des quêtes** : création et développement du système pour suivre les quêtes, les valider, enchaîner les nouvelles et faire progresser le scénario.  
- **Interactions PNJ et objets** : gestion des dialogues, des interactions avec les personnages et les objets de quête.  
- **Intégration 3D & Blueprints** : importation et configuration des modèles 3D, animation des personnages, mise en place des blueprints de comportement.  
- **Widgets et HUD** : ajout d’interfaces in-game pour guider le joueur (journal de quêtes, dialogues, indices).  
- **IHM immersive** : conception d’interfaces de description des quêtes et d’affichage des dialogues à proximité des PNJ.  

## Fonctionnalités principales 

- Un **système de quêtes** basique mais fonctionnel.  
- **Interactions avec PNJ et objets**.  
- **Progression scénarisée** par l’enchaînement des quêtes.  
- **Interface in-game** avec journal de quêtes et dialogues.  
- Un **premier monde jouable et immersif**, mettant en avant les mécaniques essentielles de gameplay.  

## Installation

1. **Télécharger le build** depuis le dépôt ou cloner le dépôt :
   ```bash
   git clone https://github.com/Mehdi-Mns/Fragmentia-Build
   ```
   (Seul le build est disponible, le projet Unreal n’est pas inclus.)  

2. **Extraire l’archive** dans le dossier de votre choix.  

3. **Lancer le jeu** en exécutant :  
   ```bash
   Game.exe
   ```

## Notes importantes ⚠️

- Le deuxième monde du jeu n’a pas survécu à la migration sous Unreal Engine ni à la mise au propre pour la génération du build.
- Quelques bugs d’affichage de widgets peuvent apparaître, mais le jeu reste fonctionnel et permet d’expérimenter les mécaniques de gameplay développées.
- Ce projet donne un aperçu des thèmes et features travaillés : gameplay, interactions, intégration de modèles et interfaces; c'est normal qu'il n'est pas parfait et pas encore fini.
